# Deploy Flutter Web no GitHub Pages

O workflow `flutter-web-pages` publica `build/web` após push em `main` ou execução manual. A URL esperada é `https://aloisiomagalhaes.github.io/template-flutter/`.

A publicação só é considerada validada quando o job `deploy` termina com sucesso e a URL responde. GitHub Pages é uma demonstração Web; não prova compatibilidade UWP, Windows ou Xbox.
